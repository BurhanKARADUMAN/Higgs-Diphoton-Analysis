# Contributing to Higgs Diphoton Analysis

Contributions to documentation, code quality, experimental reproducibility and new tests are welcome.

- Distinguish synthetic demonstrations from ATLAS Open Data and historical logs.
- Never relabel S/√B as a calibrated Z or Gaussian width as a mass uncertainty.
- Record any changed physics selections, random seeds, datasets, units and sample weights.
- Add tests for kinematics, statistics or feature validation changes.
- Never commit unlicensed collision data or large outputs without provenance.
- Preserve the historical C++ ROOT/TMVA macros rather than retroactively overwriting the original experiment.
